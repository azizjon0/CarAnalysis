## Model Performance

The final model selected for this project is **LightGBM**, based on its strong performance and stability across different data segments.

### Metrics
- **R² Score:** 0.9616  
- **MAE:** 1152.53  
- **RMSE:** 83.67 (log scale)

### Why LightGBM?

LightGBM was chosen over other models because:
- It provides **consistently stable predictions** across different segments of the data
- It handles **non-linear relationships** effectively
- It performs well with **mixed feature types** (numerical + categorical)
- It offers a good balance between **accuracy and generalization**
